# 確率

| 用語     | 意味                                                     | 例                                           |
| :------- | :------------------------------------------------------- | :------------------------------------------- |
| 試行     | その結果が予想通りになるかどうか実験や観察を行い試すこと |                                              |
| 事象     | 試行によって起こった結果                                 |                                              |
| 複合事象 | 分解が可能な事象                                         | 2, 4, 6の3つの目うちどれかが出る             |
| 根元事象 | これ以上分解することのできない事象                       | 2の目が出る                                  |
| 余事象   | ある場合以外の事象                                       |                                              |
| 空事象   | 存在しない事象                                           |                                              |
| 排反事象 | 同時に起こらない事象                                     | 偶数の目が出る事象と奇数の目が出る事象の関係 |
| 和事象   | 2つの事象AとBのうちAまたはBが起こる事象                  |                                              |
| 積事象   | 2つの事象AとBのうちAとBが同時に起こる事象                |                                              |

- 定義
  - 根源事象がn個存在し、そのうち事象Aに含まれる根元事象が全部でk個あるとき、事象Aが起こる確率 $ P(A) $
  - $ P(A)=\displaystyle \frac{k}{n} $
